## List of tools I require for my linux setup

###### General

- tmux - Terminal multiplexer/session manager
- starship - prompt configuration
- unzip
- bat (batcat) - prettier version of cat
- htop - process inspector
- C compiler for compiling packages if required - **sudo apt install build-essential**

###### Development

- fd (fdfind for debian/apt) - Fast file searching
- rg (ripgrep) - Fast file content searching
- mvn (maven) - Package Manager for Java
- jdk - For java development
- python3 - for various system packages, and for initializing venv
- uv - Lightning fast package manager for python
